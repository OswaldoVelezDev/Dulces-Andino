## 📖 Project Overview

This repository hosts the official landing page for **Dulces Andino**. Beyond web structuring, the core technical implementation lies in integrating continuous deployment workflows connected to Microsoft Azure infrastructure.

Every commit pushed to the main branch automatically triggers a GitHub Actions pipeline that builds, validates, and deploys the latest version to **Azure Static Web Apps**.
